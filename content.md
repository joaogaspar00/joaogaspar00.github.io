# Conteúdo — marcos da missão

Lista de marcos para o "log de missão": o readout dinâmico que vai
atualizar junto à telemetria à medida que se sobe, mostrando o marco
correspondente a cada altura, com uma foto ilustrativa a acompanhar.
Este ficheiro é só para organizar o conteúdo antes de o ligar ao
código.

> **Nota:** o conteúdo final dos marcos está agora em `index.html`,
> na lista `<ol id="milestones">` — é lá que se edita. Este ficheiro
> ficou como rascunho/histórico.

## Formato de cada marco

- **Ano** (título) — usado para posicionar o marco na barra lateral
- **Frase em destaque** — a linha curta e criativa que aparece no log
- **Descrição** — um parágrafo curto com o detalhe real (cadeiras,
  funções, etc.)
- **📷 Foto** — nome de ficheiro sugerido + o que mostrar; ainda por
  enviar, tal como fizeste com o `eu.jpeg`
- **🔗 Link** — só quando faz sentido (ex: PDF da tese)

Nem todos os marcos têm de ter o mesmo peso — alguns são só uma frase,
outros têm mais contexto. O objetivo é ler como um diário de bordo, não
como uma lista de RH.
